# Contributing to Flower Hut

First off, thank you for considering contributing to Flower Hut! It is people like you who make the open-source community such an amazing place to learn, inspire, and create.

## Code of Conduct

By participating in this project, you agree to abide by our code of conduct:
- Be respectful and welcoming to all contributors.
- Focus on constructive feedback and collaboration.
- Ensure a clean, safe, and professional environment.

## How Can I Contribute?

### Reporting Bugs
If you find a bug, please open an issue on GitHub. Include:
- A clear and descriptive title.
- Steps to reproduce the bug.
- Expected vs. actual behavior.
- Screenshots or console logs if applicable.

### Suggesting Enhancements
Enhancement suggestions are welcome! Please open an issue explaining:
- The goal of the enhancement.
- A detailed description of the proposed behavior.
- Why this enhancement would be useful for users.

### Submitting Pull Requests
1. Fork the repository and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. Ensure the project builds and runs locally without errors.
4. Use descriptive commit messages following the Conventional Commits specification.
   - Example: `feat: add dark mode toggler` or `fix: improve mobile navbar alignment`
5. Open a Pull Request referencing the original issue.

## Style Guide

### HTML & CSS Style Guide
- Use semantic HTML5 elements.
- Keep CSS variables organized at the `:root` level.
- Ensure all layouts are mobile-first and fully responsive.
- Adhere to WCAG 2.2 AA accessibility standards (proper alt tags, color contrasts, and keyboard focus states).

### JavaScript Style Guide
- Write clean, modern, and readable ES6+ JavaScript.
- Avoid global variables by encapsulating logic.
- Comment complex algorithms or non-obvious configurations.
